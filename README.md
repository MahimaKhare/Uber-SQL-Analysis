# Uber-SQL-Analysis


## Project Overview
This project analyzes Uber ride data using SQL to derive insights related to customer behavior, ride cancellations, payment modes, and vehicle performance.

The analysis includes:
- Data filtering & aggregation
- Analytical SQL queries
- Views creation for modular data insights

---

## Tech Stack
- SQL
- PostgreSQL 
- PDF report of queries & output

---

## Key Insights & Queries

| Query Objective | Description |
|-----------------|-------------|
| Successful rides | Retrieved all successful bookings |
| Distance by vehicle type | Average trip distance grouped by vehicle |
| Cancellations by customer | Counted total cancelled rides by customer |
| Top customers | Top 5 users based on ride bookings |
| Cancellation reason | Driver cancellation for personal/car issues |
| Ratings | Max/Min driver rating for Prime Sedan |
| UPI Payments | Filtered rides paid via UPI |
| Customer ratings | Avg rating grouped by vehicle |
| Successful ride value | Total booking value of successful rides |
| Incomplete rides | Listed rides & reasons |
